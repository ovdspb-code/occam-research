How the task works

Each sector either contains a target or is empty, but you cannot see the true state directly. A sonar check gives one noisy clue: target sectors usually say T, and empty sectors usually say E. A single clue is still not certainty.

One-rectangle trials

Targets form one filled rectangular patch. Target sectors touch by shared sides inside that rectangle; it is not a line or a chain.

Two-rectangle trials

Targets form two separate filled rectangular patches. Each patch is side-connected and solid; the two patches do not touch.

This is not a memory test and not a speed race. Checked clues remain visible. The structure type is always named before the trial; use the known rectangle pattern to reason about sectors you did not check.

Worked example

··EE···· ·?TT?··· ·??T?E·· ·????E·· ·EE····· ········

In a one-rectangle trial, a few clues can make a whole filled patch plausible. In a two-rectangle trial, you may need to find evidence for two separate filled patches.

This explains the rule, not a required sonar-check recipe. In the real trials the true target sectors are never shown during scored trials, and clues are noisy.

What you control

  • You have a fixed sonar-check budget: usually 32 checks.
  • Repeated clicks are allowed, but each repeat uses budget.
  • Checked clues stay visible during the strike phase, so this is not a memory test.
  • In B0 shakedown rounds, you will make 8 strike decisions. In B0.5/B0.6 calibration and the full pilot, there are 12. Each decision highlights two unverified sectors directly on the grid. Click the sector more likely to contain a target.
  • Practice rounds reveal the true rectangular target patch or patches right away. Scored rounds are revealed together at the end, so the later rounds stay fair.
There is no single required click pattern. The practice trials are there so you can get comfortable before scored trials begin.

Debrief

The task compares two known hidden structures: one filled rectangular target patch versus two separate filled rectangular target patches. We are testing whether people can use the named structure to make useful strike choices after limited noisy sonar checks.
