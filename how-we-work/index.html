How we work

We define the question, state the assumptions and identify what evidence would change the answer.

Frame the question

Choose a question with an observable consequence or a precise mathematical statement. Set out the model and where its assumptions apply.

Test the explanation

Use proofs, numerical comparisons or data according to the question. When simulating transport, compare with matched baselines and altered network structure.

Publish the record

Give the result a stable source and state its limits. Where available, link the manuscript, data, code and reproducing materials from the same catalogue record.

Duellum Veritatis

Each issue puts a scientific claim alongside a developed objection and records which conclusions the evidence supports within the scope examined.
