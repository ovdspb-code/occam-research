## 2. Strict complementarity и второй порядок

В положительных локальных координатах `f=(x,y,z)` ограничения имеют вид

    0<f_i<C0_i,   M(f)≤P,
    M(f)=sum C0+x+y+z+xy/z+xz/y+yz/x.

Все edge-неравенства у `p` строгие, поэтому активно только материальное ограничение. Однородность `M(f)−sum C0` степени один даёт

    f·∇M(f)=M(f)−sum C0=R>0   при M=P.

Следовательно, `∇M(p)≠0` (LICQ). Необходимые условия KKT дают

    ∇ell(p)+lambda ∇M(p)=0,   lambda≥0.

Из `∇ell(p)≠0` следует `lambda>0`. Это строгое дополнение, нужное для устойчивости активности ограничения.

Новый guarded rigidity-сертификат даёт положительно определённый Hessian функции `ell` в двумерном насыщенном chart около `p`. Он равен ограничению Hessian лагранжиана `L=ell+lambda(M−P)` на касательное пространство. Действительно, для chart `f=phi(q)`, `M(phi(q))=P`, производные второго порядка дают

    D²(ell∘phi)=Dphi^T [D²ell+lambda D²M] Dphi

в стационарной точке; члены с `D²phi` сокращаются по KKT и постоянству материала. Поэтому установленное в chart положительное определение — именно constrained SOSC, а не ошибочная замена Hessian лагранжиана ambient-Hessian функции.

## 3. Продолжение по геометрии работы

Параметризуем направленный рабочий треугольник двумя векторами `w=(a1,a2)`:

    C0 → C0+rho a1 → C0+rho a2 → C0,
    ell_w(f)=||K(f)^−1a1||
             +||K(f)^−1(a2−a1)||+||K(f)^−1a2||.

В исходной точке все три стороны ненулевые; это сохраняется в открытой окрестности. Поэтому `ell_w` гладка по `f,w` около `p`. Рассмотрим систему

    ∇_f ell_w(f)+lambda ∇M(f)=0,
    M(f)−P=0.

Её производная по `(f,lambda)` — bordered KKT-матрица

    [ H_L   ∇M ]
    [ ∇M^T   0 ].

Она обратима: если `H_L v+alpha∇M=0`, `∇M^Tv=0`, умножение на `v` и SOSC дают `v=0`, затем LICQ даёт `alpha=0`. Теорема о неявной функции даёт единственную гладкую ветвь `f(w),lambda(w)` около исходной пары. По непрерывности сохраняются положительность всех шести связей, `lambda(w)>0` и SOSC; следовательно ветвь задаёт активный строгий локальный минимум.

Нужно также исключить другие близкие минимумы. При достаточно малой общей окрестности `∇_f ell_w` остаётся ненулевым, поэтому interior-минимум с `M<P` в ней невозможен. Любой активный минимум удовлетворяет KKT; его множитель выражается непрерывно как

    lambda=−(∇ell_w·∇M)/||∇M||².

Он близок к исходному, а локальная единственность KKT-ветви исключает второй активный минимум в этой окрестности. Это обязательный шаг: один строгий локальный минимум сам по себе ещё не исключал бы соседнюю ветвь.

## 4. Компактность превращает локальный вывод в глобальный

Материальное замыкание исходного физического слоя компактно, и `K` имеет принятую непрерывную SPD-продолженность с общим `K≥lambda0 I`. Для исходной геометрии единственность `p` даёт положительный глобальный зазор вне любой достаточно малой фиксированной окрестности `V`:

    min_(g∉V) ell_w0(g) − ell_w0(p) = eta >0.

По неравенству треугольника, равномерно на всём замыкании,

    |ell_w(g)−ell_w0(g)|
       ≤2 lambda0^−1 (||a1−a1,0||+||a2−a2,0||).

При достаточно малом изменении геометрии этот модуль и непрерывность значения на `p(w)` сохраняют строгий зазор вне `V`. Глобальный минимум существует и обязан лежать в `V`; §3 оставляет там только `p(w)`. Поэтому **полный** `A_stat(w)={p(w)}`. Это также выводит положительность и насыщение новых глобальных минимумов, используя строгие исходные условия; отдельное предположение H/S для каждого `w` не добавляется.

## 5. Что это даёт физическому будущему

Для каждой одной заранее объявленной геометрии из полученной открытой области действует прежний абсолютный терминальный отбор: при `rho→0`, `N=floor(S/rho²)` и excess→0 реальные концы сходятся к `p(w)`. Работа остаётся направленной и повторяется в своём объявленном порядке. Параметр `w` не выбирается после раскрытия будущего запроса.

Все `p(w)` лежат в одной положительной безопасной окрестности на слое `C0`. Оплаченный двусторонний мост и гладкость `p(w)` дают для прежнего фиксированного будущего семейства

    sup_||v||=1 U|D_(tau,v)(p(w))−D_(tau,v)(p(w'))|
       ≤C||p(w)−p(w')||^(1/3)
       ≤C'||w−w'||^(1/3).

Конечность всех исходных будущих цен переносится мостом, поэтому вычитание корректно. Новые `tau`, радиус открытой области, явное вычисление `D` и uniform-порог по `rho` на всей открытой области здесь не заявляются. Для каждой фиксированной геометрии определимость следует без дополнительного `tau_inv`.
